# Учёт личных трат (Go + SQLite)

Учебный проект. Реализованы этапы 1–4 семестрового задания.

## Возможности

- HTTP‑сервер на `net/http` (без сторонних веб‑фреймворков).
- Серверный рендеринг HTML через `html/template`.
- SQLite через `database/sql` + драйвер `modernc.org/sqlite`.
- Слой репозитория: весь SQL изолирован от HTTP‑обработчиков.
- CRUD трат: создание, просмотр, редактирование, удаление.
- Категории трат (связь через `category_id` и `JOIN`).
- Фильтрация списка трат по категории и диапазону дат
  (query‑параметры `?category=…&from=…&to=…`).
- Валидация формы на сервере (базовая — расширяется на этапе 7).
