## Авторизация

- Регистрация: `/register` (email + пароль, минимум 6 символов).
- Вход: `/login`.
- Выход: кнопка «Выйти» в шапке (POST `/logout`).
- Пароли хранятся в виде bcrypt-хэша.
- Сессия — cookie `session_id` (HttpOnly, SameSite=Lax), TTL 7 дней.
- Все страницы трат защищены middleware `requireAuth`.
- Каждый пользователь видит и редактирует только свои траты.
